# Measles Data Analysis
## Project Discription

My project analyzes reported measles cases in five European countries (Netherlands, Belgium, Germany, France and Italy) between the years 2015 and 2024.

Research Question:

Which selceted European country had the highest number of reported measles cases between the years of 2015 and 2024, and how did the case number change of this time period?

## Dataset

The dataset used contains the reported measles cases by country and year.

Source: Our World in Data

File used:
reported-cases-of-measles.csv

## Countries Analyzed

- Netherlands
- Belgium
- Germany
- France
- Italy

## Requirements

- R 
- Visual Studio Code
- PDF Viewer 

## How to Run the Code

1. Place the File 'Analysis.R' and the File 'reported-cases-of-measles.csv' in the same Folder.
2. Open the MAT2007 Project Folder in Visual Studio Code.
3. Run 'Analysis.R'

## Data Analysis

- Rename the measles cases column for easier use.
- Select the five countries used in the Analysis.
- Filter the dataset to the years 2015-2024.
- Calculate the total reported measles cases for each chosen country.
- Identify the country with the highest number of measles cases.
- Identify the peak number of measles cases and the peak year for each of the chosen countries.
- Visualize the results using plots.

## Results

Italy had the highest total number of reported cases among the selected countries, with 9,722 cases.

The analysis found substantial variation in reported cases between countries and years.
